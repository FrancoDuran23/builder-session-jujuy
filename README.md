# Builder Session Jujuy

Landing estática de la Builder Session de Jujuy de la hackathon **Agents on Open Rails** (Celo Core Co. × Ripio).

Sábado 17/10, de 18:00 a 20:00 (hora argentina), en MINTA Café & Coworking, Salta 1079, San Salvador de Jujuy. Host: Franco Durán (@fdurandev).

`index.html` está en la raíz para que GitHub Pages lo sirva desde `main` en `/`. No hay build. `.nojekyll` evita que Jekyll procese la página.

## Publicar

Settings → Pages → Deploy from a branch → `main` / `/ (root)`.
